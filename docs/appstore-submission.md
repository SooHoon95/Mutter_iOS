iTunes Search API(KR)로 후보 전량을 조회한 결과, 큰 단어 대부분이 **다른 카테고리 앱이 장악**해 편지앱은 노출돼도 전환이 안 되는 함정이었다. 함정을 걷어내면 뮤터와 의도가 맞는 풀이 크지 않다 → 필드가 남는 게 정상.

**시즌 키워드는 저ROI 판정** — 발렌타인·화이트데이(공포게임!)·수능(공부앱)·크리스마스(게임/카드메이커) 전부 다른 카테고리가 장악. 키워드 슬롯을 태울 값어치 없음. **시즌 마케팅은 심사 없이 수시 수정 가능한 "프로모션 텍스트"로** 처리한다(크리스마스/어버이날 정도만 키워드 실험 여지, 실유입 확인 후 판단).

**키워드 전략 (ASO) — 스택 전체를 하나의 세트로 설계**

iOS 검색은 **이름·부제·키워드 3개 필드의 단어를 자동 조합**해 색인한다(설명문은 검색 색인 안 됨 — 전환용). 그래서 세 필드를 따로 보지 말고 하나의 단어 세트로 짠다. 가중치: **이름 ≫ 부제 > 키워드**.

- **이름·부제에 고가치·제품일치 단어를 몰아넣는다** — 이름 `뮤터 - 음악 편지, 노래 선물` + 부제 `생일·기념일·고백, 마음을 담은 감성 편지`가 `음악·편지·노래·선물·생일·기념일·고백·감성`을 확보. 조합으로 **음악편지·노래편지·노래선물·음악선물·생일편지·기념일편지·감성편지·고백편지·생일선물·기념일선물**이 전부 공짜 커버된다. (예전엔 `음악편지`를 통으로 넣어 조합 하나에 5자를 낭비했다.)
- **키워드 필드는 데이터로 검증한 의도 일치 단어만** — 이름/부제 토큰(음악·편지·노래·선물·생일·기념일·고백·감성)은 조합으로 커버되니 제외하고, iTunes API로 경쟁·의도를 확인해 함정을 버린다. 그 결과가 위 58자 세트. **남는 슬롯을 억지로 채우지 않는다**(패딩 = 전환·랭킹 손해).
- **`롤링페이퍼` 제외** — 뮤터는 1:1 단독 편지이지 여러 명이 돌려쓰는 롤링페이퍼가 아니다(검증: 전용 경쟁 앱 다수). 검색량은 크지만 **의도가 다른 사용자 → 미설치 → 전환율(=랭킹 신호) 하락**.
- **초경쟁어(편지·손편지·편지쓰기)는 랭킹 기대 없이** 보험용으로만. 다운로드 속도·평점이 쌓이며 서서히 오른다.
