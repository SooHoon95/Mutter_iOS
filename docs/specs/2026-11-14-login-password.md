# 로그인 비밀번호 설정 — 3플랫폼 공통 규칙 (2026-11-14)

## 문제
- 앱(iOS·Android)은 이메일 6자리 코드로만 가입한다. Supabase는 OTP 가입자에게 아무도 모르는 임의 비밀번호를 넣는다.
- 웹은 가입 시 입력한 비밀번호만 저장한다. 코드로 가입한 뒤 비밀번호를 정하거나 바꾸는 경로가 세 플랫폼 어디에도 없다.
- 그래서 앱 가입자는 로그인 화면의 "비밀번호로 로그인"이 항상 실패하고, iOS는 실패 원인을 일반 문구로만 보여 준다.

## 서버
변경 없음. Supabase Auth 기본 기능만 쓴다.
- 설정·변경: `auth.updateUser({ password, data: { password_set: true } })`
- `user_metadata.password_set == true` = 사용자가 직접 비밀번호를 정했다는 표시(클라이언트 표시용 힌트일 뿐, 보안 판단에 쓰지 않는다).

## 대상 계정
`app_metadata.provider == "email"`인 계정만. 소셜(kakao·google·apple) 계정은 이메일이 내부용(`*.mutter.local`, Apple relay)이라 비밀번호 기능을 보이지 않는다.

## 규칙
- 비밀번호 6자 이상(Supabase 최소값, 웹 가입과 동일). 확인 입력이 일치해야 저장.
- **앱 코드 로그인 직후**: 대상 계정이고 `password_set`이 아니면 "비밀번호 설정" 단계를 띄운다.
  - 안내: "비밀번호를 정해 두면 다음부터 코드 없이 로그인할 수 있어요."
  - 버튼: "저장하고 시작"(비밀번호·확인 입력) / "나중에 하기"(건너뛰고 그대로 진입).
  - 저장 실패는 진입을 막지 않는다 — 오류 문구를 보여 주고 "나중에 하기"로 넘어갈 수 있다.
- **프로필(웹은 마이페이지)**: 대상 계정에 "로그인 비밀번호" 항목. 값 = `password_set`이면 "설정됨", 아니면 "설정하기". 누르면 새 비밀번호 + 확인 입력 → 저장 → "비밀번호를 저장했어요" 토스트.
- 비밀번호를 잊으면 코드로 로그인 → 프로필에서 다시 설정(별도 재설정 메일 없음).

## 앱 로그인·회원가입 화면 (2차, 웹 구조와 맞춤)
- **로그인 화면 기본 단계 = 비밀번호 로그인**: 이메일 + 비밀번호 → "로그인". 아래에 "코드로 로그인", "이메일로 회원가입하기", 소셜 버튼.
- **코드로 로그인**: 이메일 → "코드 받기" → 코드 입력(기존 흐름). 이메일 칸 아래 가입 안내 문구는 없앤다(회원가입 버튼이 따로 있으므로).
- **이메일로 회원가입하기**(새 단계): 이메일 + 비밀번호(6자 이상) + 확인 → "인증 코드 받기"(`signInWithOTP`, createUser=true) → 코드 입력 → 인증 성공 즉시 입력한 비밀번호를 `updateUser(password, password_set=true)`로 저장 → 닉네임 → 메인. 웹 가입과 같은 순서.
  - 비밀번호 저장이 실패하면 진입을 막지 않고 "비밀번호 설정" 단계로 보내 오류를 보이고 다시 저장하거나 "나중에 하기"를 고르게 한다.
  - 이미 가입된 이메일이면 코드 인증으로 로그인되고 비밀번호가 입력한 값으로 바뀐다(웹과 동일).
  - 이때 입력한 값이 지금 비밀번호와 같아 `same_password`가 오면 성공으로 보고 그대로 진입한다.
- 코드 로그인 직후 비밀번호 설정 단계(1차)는 유지한다 — 이미 코드로 가입한 사용자용.

## 오류 문구 (Supabase `error_code` 기준, 세 플랫폼 동일)
| error_code / 조건 | 문구 |
|---|---|
| `invalid_credentials` | 이메일 또는 비밀번호가 맞지 않아요. 비밀번호를 정한 적이 없다면 코드로 로그인해 주세요. |
| `email_not_confirmed` | 이메일 인증이 아직 끝나지 않았어요. 코드로 로그인해 주세요. |
| `weak_password` | 비밀번호는 6자 이상이어야 해요. |
| `same_password` | 지금 쓰는 비밀번호와 다른 비밀번호를 입력해 주세요. |
| `reauthentication_needed` | 보안을 위해 코드로 다시 로그인한 뒤 설정해 주세요. |
| `over_email_send_rate_limit` | 코드 메일을 너무 자주 요청했어요. 잠시 후 다시 시도해 주세요. |
| (클라이언트) 확인 불일치 | 비밀번호가 서로 달라요. |
