# 새 소식 안내 — 업데이트한 사람에게 한 번 뜨는 넘겨 보는 화면 (iOS · Android · 웹)

편지권(영구 편지·7일 편지)이 생기면서 기존 사용자가 겪는 변화를, 앱을 열 때 한 번 실제 화면 캡처와 설명으로 보여 준다.
시안: 넘겨 보는 다섯 장(그림 + 제목 + 설명 두 줄). 규칙의 근거는 `permanent-letter-contract.md`.

## 언제 뜨나 (앱)

기기에 저장하는 값 하나(`whatsNewTickets`)로 정한다. 값은 없음 → `pending` → `seen`.

1. 스플래시가 끝나 세션 확인이 된 시점에 값이 **없으면**: 로그인돼 있으면 `pending`(이전 버전을 쓰던 사람), 아니면 `seen`(새로 설치한 사람 — 띄우지 않는다).
2. 값이 `pending`이고 로그인돼 있으면 `get_my_entitlements`를 받아 **`paid_enabled == true`이고 `is_admin == false`** 일 때 띄우고 `seen`으로 바꾼다.
   아니면 그대로 둔다 — 다음에 앱을 열 때 다시 확인한다(유료 전환 전에 업데이트한 사람은 전환된 뒤 처음 열 때 본다).
3. 권한 조회가 실패하면 아무것도 하지 않는다(다음 실행 때 다시).
4. `seen`이면 다시 뜨지 않는다. 편지를 읽는 화면(딥링크로 열린 뷰어) 위에는 띄우지 않는다 — 메인 탭이 보이는 상태에서만.

## 화면 (앱)

전체 화면으로 덮는다. 위에서 아래로:

- 오른쪽 위 글자 버튼 `건너뛰기`(마지막 장에서는 숨김)
- 좌우로 넘기는 다섯 장 — 장마다 화면 캡처 한 장(둥근 모서리·옅은 테두리), 제목, 설명
- 장 표시 점 다섯 개(현재 장은 길게)
- 기본 버튼 `다음`(마지막 장에서는 `시작하기`)

`건너뛰기`·`시작하기`를 누르면 닫힌다. 확인 팝업 없음. 배경은 아이보리, 버튼은 기존 기본 버튼.

## 다섯 장

설명은 **문장마다 줄을 바꾼다**. 일수는 서버 값(`free_days`·`grace_days`)을 넣는다 — 아래 7·30은 지금 값.

| 장 | 그림 | 제목 | 설명 |
|---|---|---|---|
| 1 | 보낸 편지 목록(영구 표시만 보이는 목록) | `지금까지 보낸 편지는 그대로예요` | `이미 보낸 편지는 기간 제한 없이 계속 열려요.` / `달라지는 건 앞으로 보내는 새 편지예요.` |
| 2 | 보내기 전 선택 카드 | `새 편지는 보낼 때 골라요` | `영구 편지는 편지권 1장으로 기간 제한 없이 보내요.` / `{free_days}일 편지는 무료로 보낼 수 있어요.` |
| 3 | 받은 편지 끝의 안내 | `{free_days}일 편지는 {free_days}일 동안 열려요` | `받는 분이 처음 연 날부터 {free_days}일이에요.` / `닫힌 뒤 {grace_days}일이 지나면 편지와 사진이 삭제돼요.` |
| 4 | 잠김 화면 | `닫힌 편지도 간직할 수 있어요` | `삭제되기 전까지 편지권 1장으로 다시 열 수 있어요.` / `보낸 사람도, 받은 사람도 할 수 있어요.` |
| 5 | 편지권 구매 시트 | `편지권은 필요할 때 바로` | `편지권이 없으면 그 자리에서 살 수 있어요.` / `가진 편지권은 프로필에서 볼 수 있어요.` |

- 그림은 각 플랫폼에서 찍은 실제 화면에서 해당 부분만 자른 것(폭 720px JPEG). iOS는 이미지 카탈로그 `WhatsNew1`~`WhatsNew5`,
  Android는 `uicomponent`의 `drawable-nodpi/whatsnew_1`~`whatsnew_5`.
- 그림에는 한국어 화면이 찍혀 있다. 영어 설정에서도 같은 그림을 쓰고 제목·설명만 영어로 보인다.
- 그림마다 화면 낭독용 설명(대체 문구)을 붙인다 — 제목을 그대로 쓴다.

## 다시 보기

프로필에 `새 소식` 줄을 둔다(편지권 UI가 보이는 계정에만: `paid_enabled || is_admin`). 누르면 같은 화면이 열린다. 저장 값은 건드리지 않는다.

## 웹

넘겨 보는 화면은 만들지 않는다. 로그인한 사용자 중 `paid_enabled == true`이고 관리자가 아닌 계정에게, 로그인 뒤 화면들의 내비게이션 아래에 닫을 수 있는 한 줄을 보인다.

- 문구: `편지권이 생겼어요. 새 편지는 보낼 때 영구 편지와 {free_days}일 편지 중에 골라요. 지금까지 보낸 편지는 그대로예요.`
- 오른쪽에 `닫기`. 닫으면 그 브라우저에서는 다시 보이지 않는다(localStorage `whatsNewTickets = seen`).
