## 2. 자동 마케팅 루프 — Claude 사용량 [실측]

### 2-1. 요금제 상황

| 항목 | 값 |
|---|---|
| 로그인 방식 | claude.ai (구독) |
| 요금제 | Claude **Team** |
| 추가 사용량(Extra usage) | **켜짐** — 요금제 한도를 넘으면 API 단가로 자동 과금 |
| 루프가 쓰는 모델 | Claude Fable 5.1 (`model: inherit` → 세션 기본 모델) |

즉 **평소에는 요금제 안에서 0원**이지만, 같은 주에 대화형 작업을 많이 해서 한도를 넘긴 상태라면 루프 실행분이 추가 과금된다. 아래 금액은 "API 단가로 환산하면 이 정도"라는 상한선이다.

### 2-2. 실행 1회당 사용량 (2026-10-05 실제 실행 기록)

| 실행 | 내용 | 입력 | 출력 | 캐시 읽기 | 캐시 쓰기 |
|---|---|---|---|---|---|
| 1회차 | 리드 + ASO 분석가 + 카피라이터(한글날 초안 4건) | 2,562 | 190,818 | 5,177,819 | 1,110,029 |
| 2회차 | 리드만(초안 이미 있어 위임 생략) | 1,226 | 51,740 | 2,199,915 | 307,352 |
| 회귀 테스트 1케이스 | 한 줄 소개 2안 | 202 | 12,536 | 440,302 | 130,898 |

### 2-3. API 단가로 환산 [공시 단가 × 실측]

단가(100만 토큰당): Fable 5.1 입력 $10 · 출력 $50 · 캐시 읽기 $0.25 · 캐시 쓰기 $12.50~$20(5분/1시간 TTL) / Sonnet 5.5 입력 $2 · 출력 $10 · 캐시 읽기 $0.20 · 캐시 쓰기 $2.50~$4

| 실행 유형 | Fable 5.1 | Sonnet 5.5로 바꾸면 |
|---|---|---|
| 위임 있는 주(시즌·순위 변동·월간 점검) | **$25~33 (약 3.3만~4.4만 원)** | $5~7 (약 0.7만~0.9만 원) |
| 위임 없는 주(변화 없음) | $7~9 (약 0.9만~1.2만 원) | $1.4~1.9 (약 0.2만~0.25만 원) |
| 회귀 테스트 5케이스 | $10~15 | $2~3 |

| 월 환산(4회, 위임 2 + 무위임 2 가정) | Fable 5.1 | Sonnet 5.5 |
|---|---|---|
| 요금제 한도 안 | **0원** | **0원** |
| 한도 초과로 전부 추가 과금될 때 | 약 $64~84 (**8.6만~11.2만 원**) | 약 $13~18 (1.7만~2.4만 원) |

**비용 대부분은 출력과 캐시 쓰기다.** 리드가 실무 에이전트를 부를 때마다 새 컨텍스트가 캐시에 쓰이기 때문이다.

### 2-4. 권장 조치

| 조치 | 효과 | 품질 영향 |
|---|---|---|
| 루프 3개 에이전트(`mutter-marketer`·`aso-analyst`·`copywriter`)의 `model`을 `sonnet`으로 고정 | 월 상한 8.6만~11.2만 원 → 1.7만~2.4만 원 | 카피 품질은 회귀 테스트로 확인 후 결정 |
| claude.ai 관리 화면에서 추가 사용량 월 상한 설정 | 최악의 경우를 막음 | 없음 |
| 회귀 테스트는 플러그인 업데이트·에이전트 수정 때만 | 불필요한 실행 방지 | 없음 |

| **Hyperframes**(설치됨, 로컬 렌더) + 앱 화면 녹화 | 0원 | **0원** | **0원** |
| Veo 3.1 Lite(720p) [공시] | $0.05/초 | $2.25(약 3천 원) | 약 1.2만 원 |
| Veo 3 Fast(720p) [공시] | $0.10/초 | $4.50(약 6천 원) | 약 2.4만 원 |
| Veo 3 Standard(1080p) [공시] | $0.40/초 | $18(약 2.4만 원) | 약 9.6만 원 |
| 배경음악 | 무료 음원(YouTube 오디오 라이브러리·CC0) | 0원 | 0원 |

**권장: Hyperframes로 시작.** 뮤터 홍보 영상의 핵심은 실제 앱 화면(편지가 열리고 음악이 흐르는 장면)이라 생성형 영상이 꼭 필요하지 않다. 실사 감성 컷이 필요할 때만 Veo 3.1 Lite를 편당 3천 원 수준으로 쓴다.

> 참고: 인스타 앱 안의 음악 라이브러리는 API로 올리는 게시물에 붙일 수 없다. 음악은 무료 라이선스 음원을 영상에 직접 넣는다.

| 채널 | 과금 기준 | 한국 추정 단가 | 설치 1건당(추정) | 특징 |
|---|---|---|---|---|
| **Apple Search Ads** | 탭당(CPT) | $0.32~0.45(약 430~600원) | 약 500~900원 | App Store에서 "고백편지", "노래선물"을 검색한 사람에게 노출. 의도가 가장 강해서 1순위 |
| Meta(인스타·페북) 앱 설치 광고 | 설치당(CPI) | iOS $4~16 · Android $1.4~6.5 | 약 1,900~21,000원 | 범위가 넓다. 소재가 좋으면 아래쪽, 아니면 위쪽 |
| 유튜브 쇼츠 광고 | 노출·조회 | CPM $2~8(1천 회 노출당 약 2,700~10,700원) | 측정 어려움 | 인지도용. 설치 전환은 약함 |
