## 운영 결론과 전환 동선

릴스에서 ‘나도 써 볼 수 있는 첫 문장’을 보여 주고, 같은 장면을 스레드로 풀어 쓴다. 블로그는 전달 방법과 준비 중 생기는 질문을 답하는 검색 자산으로 쌓는다. 11/11에는 선물에 곁들일 편지와 노래 한 곡으로 연결한다. 게시량은 운영 가설이며 알고리즘 보장·검색량 주장이 아니다.

동선은 콘텐츠 → 프로필/본문 링크 → 뮤터 소개·발신 진입 → 편지 작성 → 링크 전달이다. 웹 베이스는 `https://letter-app-nine-kohl.vercel.app`지만 발신 진입·스토어 연결은 [확인 필요]. 10/12 첫 발행 전에 본인 기기에서 비로그인 랜딩·설치·작성 동선을 직접 확인한다. 확인 전에는 프로필 링크를 가리키는 초안만 둔다. 웹 개발·분석 SDK 연결은 이번 작업 범위 밖이다. 콘텐츠의 공개 링크로 실제 개인 편지 토큰을 사용하지 않는다.

릴스는 1080×1920, 얼굴·음성 없이 읽히는 2줄 자막과 실제 화면으로 만든다. Ivory #FFFDF2·Ink #221D14·액센트 #C77BAE를 사용한다. 편지 영역은 명조, 안내는 Pretendard. Hyperframes는 렌더 템플릿 제작용으로만 쓰며 유료 생성 모델을 호출하지 않는다. 미완성 템플릿은 기본 화면 녹화와 PNG 컷 연결로 대체한다.

음악 중심은 ‘이 노래를 왜 보냈는지’와 실제 음악 선택 UI로 표현한다. SoundCloud 공식 임베드 재생 권한이 영상 음원 재사용 허락을 뜻하지 않으므로 화면 녹화 소리는 끈다. 기본 마스터는 무음이다. 본인이 권리를 가진 음원만 공통 원본에 추가한다. Meta Sound Collection을 쓰는 경우에도 해당 이용조건을 확인하고 쇼츠에는 무음 원본을 쓴다. 출처: [Meta 음악 라이브러리 안내](https://www.facebook.com/help/instagram/402084904469945), [Meta 저작권 안내](https://www.facebook.com/help/354736791367645/).

## 측정과 2주 차 판단

10/12~25를 기준선으로 삼는다. 초기에 확보할 수 없는 값은 null/[미측정]으로 기록하고 0으로 대체하지 않는다. 게시 후 48시간 수치로 비교하고, 7일 누적 수치를 보조로 남긴다. 10/23 블로그는 10/25 이후 수치로 확인한다.

| 지표 | 기록 단위와 뜻 | 측정 경로·한계 |
|---|---|---|
| 저장 | 게시물 저장 수/도달 수 | 인스타 인사이트에서 제공될 때 기록, 스레드는 미제공이면 null |
| 공유 | 게시물 공유 수/도달 수 | 제공되는 공유/repost 항목을 별도 기록, 두 채널 정의를 섞지 않음 |
| 프로필 클릭 | 프로필 방문 수/도달 수 | 게시물별 미제공이면 계정 주간 합계로만 사용, 특정 릴스 귀속 금지 |
| 링크 열람 | 소개·발신 페이지 열람 세션 | 기존 웹 분석이 UTM을 보존할 때만 집계. 링크 탭과 도착 열람을 구분 |
| 보조 | 발송 편지·수신 열람 | 집계 구현 [확인 필요], 콘텐츠 성과 대신 설치 수만으로 판단하지 않음 |

UTM: `utm_source=instagram|threads|naver|youtube`, `utm_medium=organic_social|blog`, `utm_campaign=2026_pepero_content`, `utm_content=<queue id>`. IG 프로필 링크는 고정 content=profile 값으로 둔다. 게시물별 IG 링크 열람 귀속은 불가능한 상태로 시작한다. 도착 분석이 없으면 네이티브 외부 링크 탭만 대리지표로 쓰고 ‘링크 열람 미측정’을 표시한다. UTM 자체는 계측 도구가 아니다. 개인 편지 링크 열람과 공개 마케팅 랜딩 열람을 구분한다.

10/25 검토 기준은 내부 실험 기준이며 업계 평균이 아니다.
- 릴스 3편 각각 도달 100 이상이고 비교 후보 2편 이상이면, 저장+공유율이 다른 후보보다 1.5배 이상이고 합산 행동 5건 이상인 주제를 3주차에 한 편 더 반복한다. 도달이 100 미만이면 승패 판정 대신 훅 한 줄만 바꿔 2주 더 확인한다.
- 저장·공유는 생겼는데 계정 프로필 방문이 2주 합계 5회 미만이면 마지막 3초의 제품명·프로필 CTA를 더 선명히 바꾼다. 특정 게시물 원인으로 단정하지 않는다.
- 프로필 방문 20회 이상인데 외부 링크 탭 0이면 링크·소개문·발신 동선을 먼저 직접 재확인한다. 링크 열람이 미측정이면 전환율을 계산하지 않는다.
- 사용자 실작업이 2주 모두 180분을 넘으면 릴스를 주 1편으로 낮추고 스레드 2편·블로그 월 2편을 유지한다. 쇼츠는 먼저 생략한다.
- 11/11 성과는 게시 후 48시간인 11/13에 별도 회고한다. 계정 주간 지표로 콘텐츠의 인과 효과를 단정하지 않는다.

`marketing/data/social/<수집일>.json` 수기 입력 권장 필드: post_id, queue_id, channel, published_at, measured_at, window_hours, pillar, format, first_line, reach, saves, shares, profile_visits, external_link_taps, landing_views, manual_minutes, metric_scope(post/account), note. 실제 게시물 URL·작성 시각과 측정 범위를 함께 남기고 미제공은 null. 기존 자동 수집기나 확정 JSON 스키마가 있다는 뜻은 아니다. 사람은 플랫폼 수치를 복사하고 에이전트는 정리·상위 3개 형식과 첫 줄 요약을 한다.
