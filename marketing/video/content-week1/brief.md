# 1주차 무료 영상 제작 핸드오프

요청: 10/12·10/16 릴스 두 편을 얼굴 없는 무료 화면 녹화/텍스트 영상으로 제작할 때 사용할 브리프.
사용 스킬: 리드 content-strategy·social. 영상 제작은 mutter-video-director에 위임 필요.
소스: `.agents/product-marketing.md` v2.1, verified_commit 0458ce3; 1주차 reel 큐 두 파일. API 미호출·순위 미인용·신선도 대상 신규 커밋 0.

목적: 편지 시작 부담과 상대 설치 부담을 줄여 프로필 링크에서 작성으로 이어지게 한다.
플랫폼: 인스타 릴스 9:16 1080×1920. 길이: 두 편 각각 16초. 선택 쇼츠는 무음 원본 재사용.
핵심 메시지: 첫문장은 오늘의 장면에서 시작한다. 편지에 노래 한 곡을 담고, 받는 사람은 웹 링크로 읽는다.
CTA: 프로필 링크에서 뮤터를 확인하고 오늘 떠오른 사람에게 편지를 쓴다. 실제 링크 동선은 사람이 발행 전에 확인한다.

입력: `marketing/queue/2026-10-12-reel-content-first-line.md` 및 `2026-10-16-reel-content-no-install.md`의 추천 샷·자막·캡션. 실제 앱·웹 수신 무음 녹화 각 1개, 자체 창작 편지, 개인정보 없는 화면. 실제 UI를 요청하고 기능 화면을 만들어 꾸미지 않는다.
제작: 동일 Hyperframes 자막 템플릿으로 두 편 제작. HTML→PNG 예문 카드, 화면녹화 컷 연결만 사용. 유료 도구·생성 영상 API·음원 다운로드 없이 구현. Ivory #FFFDF2, Ink #221D14, 액센트 #C77BAE. 편지 명조·안내 Pretendard. 자막은 2줄 이내, 화면 UI와 겹침을 출력 미리보기로 확인.
오디오: 기본 무음 마스터. SoundCloud 음원은 녹화에 넣지 않는다. 공통 음원을 쓰려면 자체 권리 확인된 파일만 사용. 음악 기능은 선택 UI와 자막으로 설명하고 재생을 보장하지 않는다.
작업 예산: 초기 설정 사용자 30분, 각 영상 템플릿 적용 35분. 렌더 준비가 늦으면 화면 녹화+PNG 컷 연결로 단순화한다.
수용 기준: 첫 3초 훅·16초 길이·무음으로 내용 이해·실제 UI·단일 CTA·개인정보 없음·큐 status draft. 렌더 파일을 사람이 확인한 뒤 승인한다. 이 브리프에 영상 모델 프롬프트는 포함하지 않는다.
