- **현재 상태**: 자동 게시는 구현만 끝났고 꺼져 있습니다. 실제 게시는 아직 한 번도 하지 않았고, 첫 시험은 11-13 카드입니다.

## 3. 자동화 버전 A to Z

대상: 인스타 카드, 스레드 글. Mac이 켜져 있고 로그인돼 있어야 합니다.

### A. 상태 확인
Claude Code에 "발행 상태 확인해줘"라고 하거나 터미널에서 실행합니다.

```
cd ~/Desktop/Code/Mutter
.venv-marketing/bin/python3 scripts/marketing/social_publish.py check
```

토큰과 계정(@mu_sic_letter)이 맞는지 나옵니다. 오류가 나오면 9번 항목을 봅니다.

### B. 초안 고르기
노션 주간 계획 노트의 "이번 주 초안"에서 고릅니다. 실제 파일은 저장소의 `marketing/queue/`에 있고, 카드 이미지는 같은 이름의 `.png`입니다.

### C. 승인하고 예약하기
Claude Code에 초안 이름과 시각을 말합니다.

```
/marketing-approve 2026-11-09-instagram_card-shared-song
```

Claude가 본문·이미지·계정·예약 시각을 보여 줍니다. 문구를 고치고 싶으면 이때 말합니다. "승인"이라고 답하면 예약 목록에 등록됩니다. 등록만 됐고 아직 올라가지 않습니다.

### D. 발행 켜기 (처음 한 번)
Claude Code에 "발행 켜줘"라고 하거나 실행합니다.

```
.venv-marketing/bin/python3 scripts/marketing/social_publish.py resume
```

이후로는 예약 시각이 되면 Mac이 자동으로 올립니다. 5분마다 확인하므로 최대 5분 늦을 수 있습니다.

### E. 올라갔는지 확인
```
.venv-marketing/bin/python3 scripts/marketing/social_publish.py list
```

상태가 `published`면 성공입니다. 인스타 앱에서도 직접 확인합니다.

### F. 멈추고 싶을 때
```
.venv-marketing/bin/python3 scripts/marketing/social_publish.py pause
```

바로 멈춥니다. 예약 목록은 남아 있고, 다시 켜면 이어집니다.

### 자동화 버전의 한계
- 예약 시각에 Mac이 꺼져 있으면 올라가지 않습니다. 24시간 넘게 밀린 예약은 보류되고 다시 승인해야 합니다.
- 채널당 하루 1건만 나갑니다.
- 게시 결과가 불확실하면(네트워크 끊김 등) 자동으로 다시 올리지 않고 멈춥니다. 중복 게시를 막기 위해서입니다.
- 릴스는 음악 없이 올라갑니다.
- 스토리, 댓글 답글, DM은 자동화되지 않습니다.

## 4. 수동 버전 A to Z

대상: 릴스, 스토리. 카드도 원하면 이 방식으로 올릴 수 있습니다.

### A. 올릴 것 찾기
- 카드 이미지: `marketing/queue/<초안 이름>.png` (1080×1350)
- 캡션: 같은 이름 `.md` 파일의 "캡션" 부분
- 릴스 영상: `marketing/video/<영상 폴더>/` 안의 MP4 (1080×1920)

Claude Code에 "이번 주 카드 이미지랑 캡션 보여줘"라고 하면 찾아 줍니다.

### B. 폰으로 옮기기
- 이미지·영상: Finder에서 파일을 우클릭 → 공유 → AirDrop → 내 iPhone
- 캡션: Mac에서 복사하면 같은 Apple 계정의 iPhone에서 바로 붙여넣기 됩니다

### C. 인스타 앱에서 올리기
1. @mu_sic_letter 계정인지 확인합니다.
2. **+** → 게시물(카드) 또는 릴스를 고릅니다.
3. 옮긴 파일을 선택합니다.
4. 릴스면 **음악** 버튼으로 곡을 고릅니다. 「들려줘」는 잔잔한 곡(BPM 80 안팎)에 맞춰 편집됩니다.
5. 캡션을 붙여넣습니다. 해시태그는 3~4개만 씁니다.
6. 20:30 전후에 **공유**를 누릅니다. 앱의 예약 기능으로 미리 걸어 둬도 됩니다.

### D. 올린 걸 기록하기
Claude Code에 "11-15 릴스 수동으로 올렸어"라고 말합니다. 초안 상태를 게시됨으로 바꿔 두어야 다음 주 계획이 같은 걸 다시 권하지 않습니다.

## 5. 릴스(영상) 만드는 법

릴스는 사람과 순간이 나오는 실사 컷으로만 만듭니다. 자막 슬라이드형은 만들지 않습니다.

1. Claude Code에 주제를 말합니다. 예: `/ig-reel 주제: 수능 끝난 날 교문 앞` 컨셉과 컷별 생성 프롬프트가 나옵니다.
2. Higgsfield에서 프롬프트를 넣어 컷을 뽑습니다. 설정은 9:16, 5초, 1080p. 컷마다 2~3개 뽑아 표정이 좋은 걸 고릅니다.
3. 뽑은 파일을 영상 폴더의 `clips/`에 `shot1.mp4`, `shot2.mp4` 순서로 넣습니다.
4. Claude Code에 "클립 넣었어, 편집해줘"라고 말합니다. 컷 편집, 질감 통일, 마지막 슬로건까지 넣어 MP4로 만듭니다.
5. 미리보기를 보고 고칠 점을 말합니다. 확정되면 4번 항목(수동 버전)으로 올립니다.

「들려줘」는 1번이 끝나 있습니다. 프롬프트 5개는 `marketing/video/2026-10-13-brand-film/CONCEPT.md`에 있고, 같은 폴더의 `clips/`에 넣으면 됩니다.

## 8. 지켜야 할 것

- 기능 설명은 출처가 확인된 것만 씁니다. "항상 자동재생된다", 순위, 다운로드 수는 말하지 않습니다.
- 실제 사용자의 편지 내용이나 이름은 쓰지 않습니다. 예시 편지는 직접 지은 것입니다.
- 영상에 SoundCloud나 다른 곳의 음원을 직접 넣지 않습니다. 음악은 인스타 앱에서만 얹습니다.
- 이모지와 느낌표를 쓰지 않고, 담백한 존댓말로 씁니다.
- 홍보성 댓글, 커뮤니티 홍보 글, 유료 광고는 하지 않습니다.

## 9. 문제가 생기면

- **예약 시각이 지났는데 안 올라감**: Mac이 켜져 있었는지 확인하고 3-E의 `list`로 상태를 봅니다. `expired_hold`면 다시 승인합니다.
- **상태가 `uncertain`**: 올라갔는지 불확실한 상태입니다. 인스타 앱에서 실제로 올라갔는지 확인한 뒤 Claude Code에 알려 주세요. 그 전에는 같은 채널의 다른 예약도 멈춥니다.
- **토큰 오류**: 만료됐거나 Meta 대시보드에서 바뀐 것입니다. 새 토큰을 `.env.marketing`에 넣고 Claude Code에 "토큰 다시 등록해줘"라고 합니다. 토큰은 채팅에 붙여넣지 않습니다.
- **잘못 올라감**: 인스타 앱에서 직접 삭제하고, 3-F로 발행을 멈춥니다.
- **노션에 주간 계획이 안 올라옴**: 월요일 09:00에 Mac이 꺼져 있었을 가능성이 큽니다. Claude Code에 "주간 루프 돌려줘"라고 합니다.
- **터미널 창이 자꾸 뜸**: 발행이 켜져 있으면 5분마다 잠깐 떴다 닫힙니다. 싫으면 3-F로 멈춥니다.
