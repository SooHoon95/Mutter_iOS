## 추천안
### 샷 구성·화면 자막
16초, 세로 1080×1920. 한 샷에 자막 1~2줄. 자막은 위아래 앱 버튼을 가리지 않는 중앙 여백에 배치합니다.

| 시간 | 샷 구성·무료 소스 | 화면 자막 |
|---|---|---|
| 0~3초 | Ivory 배경 HTML→PNG 카드. 첫 문장만 큰 명조로 표시 | 첫 줄은 오늘 있었던 일로 |
| 3~7초 | 실제 작성 화면 무음녹화. 아래 예시 본문 입력 부분만 확대 | “네가 알려 준 빵집을 오늘 봤어.” |
| 7~10초 | 같은 본문이 적용된 실제 classic-serif 편지지 화면 | “다음엔 같이 가고 싶어.” |
| 10~13초 | 실제 음악 선택 UI. 음악 한 곡을 설정한 상태만 보여 주기 | 편지에 노래 한 곡을 담아요 |
| 13~16초 | 편지 미리보기 실제 UI 정지 화면 위 작은 CTA 카드 | 뮤터는 프로필 링크에서 |

## 제작·게시 메모
무료 제작: 기존 테스트 편지·작성·음악 선택·웹 열람 녹화를 재사용합니다. 앱/브라우저 화면 녹화는 소리를 끄고 개인정보를 가립니다. HTML→PNG 훅·CTA 카드 2장을 만든 뒤 Hyperframes의 컷 연결·텍스트 오버레이로 편집합니다. 실제 영상 제작과 영상 모델 프롬프트는 이 초안에 포함하지 않습니다.
소요 시간: 기존 소스 선택 5분 + 카드·자막 교체 10분 + 컷 조립 10분 + 실제 UI·자막 검수 10분 = 35분. 업로드는 운영안의 공통 발행 예산에 포함합니다. 공통 소스 최초 촬영 시간은 운영안의 주간 공통 준비에 포함합니다.
음원: 기본 무음 영상. SoundCloud 소리를 녹화하거나 다운로드하지 않습니다. 자체 제작하거나 사용 권리를 확보한 음원이 있을 때만 추가합니다. 영상의 무음 상태와 앱의 음악 기능을 혼동하지 않도록 음악 기능은 자막으로 설명합니다. 자동재생 성공을 연출하거나 항상 재생된다고 약속하지 않습니다.
게시 전: 테스트 편지로 실제 화면과 표시 상태를 확인합니다. 수신 테스트는 앱이 설치되지 않은 기기의 웹 브라우저에서 실시합니다. 예시 본문은 자체 창작이며 실제 사용자 사례가 아닙니다. IG 프로필 링크의 발신·설치 안내 동선을 사람이 확인한 뒤 게시합니다.
CTA: 인스타그램 프로필 링크 확인. 캡션 URL 클릭을 전제로 하지 않습니다.
사용한 Customer Language: 확정 문장 직접 인용 없음. 첫 릴스는 쓰기 장면, 둘째 릴스는 무설치 수신 사실을 구체적으로 보여 줍니다.
추천 이유: 막막한 첫 문장을 실제 작성 화면과 연결해 바로 따라 쓸 수 있습니다.
