# marketing

Mutter 마케팅 작업을 `mutter-marketer` 에이전트에 위임한다. 포지셔닝·출시 계획·ASO·카피·광고 소재·소셜 콘텐츠·가격/페이월·경쟁 분석이 대상이다.

## 작업 순서

1. `Agent` 툴로 `subagent_type: mutter-marketer`를 호출하고, 아래 요청을 그대로 전달한다.
   - 요청: `$ARGUMENTS`
   - 요청이 비어 있으면 사용자에게 무엇을 할지 한 줄로 묻는다(예: "App Store 부제 3안", "출시 4주 플랜", "인스타 릴스 캡션 5개").
2. 에이전트 산출물 경로(`marketing/<카테고리>/…`)와 핵심 결론을 사용자에게 요약해 전달한다. 파일 전체를 다시 붙이지 않는다.
3. 영상 제작 요청이 섞여 있으면 마케터 결과를 받은 뒤 `/video-prompt`로 이어간다.
